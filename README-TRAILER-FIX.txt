YOUTUBE TRAILER / ERROR 153 FIX

Do NOT double-click index.html for the YouTube version of this site.
A file:/// URL has no normal HTTP origin/referrer, and YouTube can return
"Video player configuration error - Error 153".

Recommended:
1. Double-click START-SITE.bat.
2. Leave the command window open.
3. The browser opens http://localhost:5500/ automatically.
4. Scroll to TRAILER and play the embedded video.

Alternative with VS Code:
- Open the project folder in VS Code.
- Use the Live Server extension.
- Open index.html through Live Server.
